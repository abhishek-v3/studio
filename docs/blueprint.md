# **App Name**: GATE CS Navigator

## Core Features:

- Question Scraper: Scrape all GATE CS questions year-wise from a provided URL and save them in JSON format.
- Year-wise Question Listing: List all years for which questions are available, allowing the user to select a specific year.
- Quiz Generation: Dynamically generate a quiz interface based on the selected year's questions.
- Quiz Taking: Allow the user to take the quiz, answering questions and receiving immediate feedback (if correct/incorrect).
- Difficulty Adaptation Tool: Use AI to asses student ability based on past answers and provide an estimate of future questions difficulty
- Progress Tracking: Track the user's progress and display results.

## Style Guidelines:

- Primary color: A deep blue (#2E5266) evoking trust and focus, essential for a learning tool.
- Background color: Light grey (#F0F4F7), providing a clean, distraction-free environment.
- Accent color: A vivid orange (#FF7F50) to highlight important elements and actions.
- Body font: 'Inter', sans-serif, for a modern and readable text.
- Headline font: 'Space Grotesk', sans-serif, offering a tech-inspired feel to headings.
- Use clean, minimalist icons to represent different sections and actions within the application.
- Design a clean and intuitive layout, prioritizing ease of navigation and readability to reduce cognitive load.
- Use subtle transitions and feedback animations to enhance the user experience without being distracting.
